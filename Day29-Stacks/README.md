📘 Day 29 – Stack Using Object-Oriented Programming (OOP)

🚀 Overview

Today, I learned how to implement a Stack using Object-Oriented Programming in Python.
A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle — the last element inserted is the first one to be removed.

By using classes and objects, the stack implementation becomes more structured, reusable, and modular.

🧠 What I Learned

Stack works on LIFO principle.

Implemented main operations:

push() → Add an element to the top.

pop() → Remove and return the top element.

peek() → View the top element without removing it.

is_empty() → Check if the stack is empty.

display() → Show all elements in the stack.

Using OOP makes the implementation:

Easier to read and maintain.

Reusable for other projects.

Encapsulated (data hidden inside the class).

🧩 Real-World Applications

Undo / Redo operations in editors.

Browser history navigation.

Expression evaluation (postfix, prefix).

Function call stack in programming languages.

Backtracking algorithms (e.g., maze solving).
