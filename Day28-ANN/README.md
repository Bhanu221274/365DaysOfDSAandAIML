## 🧠 Artificial Neural Network (ANN)

Today, I implemented my first **Artificial Neural Network (ANN)** using Python and Scikit-learn!

### 🔍 What I Learned:
- ANN mimics how the human brain processes information.
- It consists of **Input**, **Hidden**, and **Output** layers.
- Each neuron passes information through **weights**, **biases**, and **activation functions**.
- Learning happens through **forward propagation** and **backpropagation**.
- ANN can learn complex, non-linear relationships better than classical ML models.

### ⚙️ Implementation Highlights:
- Used **Iris Dataset** for classification.
- Used **MLPClassifier** from `sklearn.neural_network`.
- Achieved ~97% accuracy!
- Key step: **Scaling features** with `StandardScaler` to speed up convergence.

### ⏱ Performance:
- Best suited for problems where simple ML algorithms don’t perform well.
- Applications: Image recognition, speech processing, pattern detection, etc.
